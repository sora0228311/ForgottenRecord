# Story

数年前──

山奥の極秘研究施設で事故が発生した。

調査隊は消息を絶ち、

最後の通信だけが残された。

> **「……この場所には、まだ誰かがいる。」**

数年後。

失われた記録の一部を手にした4人の探索者は、

閉鎖された洋館へ向かう。

しかし、

そこは探索者を試す施設だった。
